2026. 08. 27.

1. 오늘의 목적

실험 프로그램을 완성하고, 단일 피험자(test01) 대상으로 0단계부터 3단계까지
전 과정을 수행해 다음 두 가지를 확인한다.
 (1) 클릭 오차에 학습 가능한 개인 편향이 존재하는가
 (2) 궤적 학습 보정을 UI 인식(최근접 버튼 스냅)과 결합하면 스냅 단독보다 나은가


2. 실험 방법

전체화면 웹 프로그램으로 원형 버튼을 제시하고 클릭 좌표와 마우스 궤적을 기록했다.
궤적은 mousemove + requestAnimationFrame 으로 샘플링했으며 실측 샘플 간격은
중앙값 8ms(125Hz)로 요구치인 60Hz를 넘었다.

 - 0단계 : 버튼 크기 6/10/16/24/32px 각 30회, 총 150회
 - 1단계 : 학습 데이터 수집, 단일 버튼 400회
 - 2단계 : 단일 버튼 평가, 새로 수집한 120회
 - 3단계 : 3x3 격자 다중 버튼 평가 240회

시행마다 크기·거리(300/600px)·방향(8방향)을 무작위 배분했고, 50회마다 30초
강제 휴식을 두었다. 총 910회.

성공 판정은 원형 기준으로 클릭점과 버튼 중심의 거리가 반지름 이하일 때로 했다.
정사각형을 쓰면 접근 방향에 따라 중심-경계 거리가 0.5~0.71배로 달라져 8방향
균등 배분 설계가 무너지므로 원형으로 통일했다.


3. 실험 조건 확정 과정

3-1. 버튼 크기
0단계 150회의 크기별 성공률에 로지스틱 회귀를 적합해 목표 성공률에 해당하는
크기를 역산했다.
   6px 23.3% / 10px 50.0% / 16px 70.0% / 24px 80.0% / 32px 83.3%
   적합식 : logit(성공) = -4.054 + 1.708 x ln(크기)

당초 목표였던 90%는 최대 후보인 32px에서도 성공률이 83.3%에 그쳐 산출 크기가
관측 범위를 벗어났다(외삽). 목표를 75/80/85%로 낮춰 20 / 24 / 30px 을 얻었고
세 값 모두 실측 범위 안에 있다.

3-2. 개인 오차 표준편차
1단계 379시행의 클릭-중심 거리 표준편차로 sigma = 5.535px 를 얻었다.
3단계 버튼 간격은 이 값의 0배 / 1배 / 3배(0 / 5.53 / 16.60px)로 설정했다.


4. 결과

4-1. 1단계 (400회, 분석 375)
   성공률 73.4%, 평균 오차 9.30px, 반응시간 중앙값 647ms
   시행번호에 따른 오차 증가 추세 없음 (r = 0.022, 400회에 +0.42px)
   → 760회 구간에서 유의한 피로 효과는 관찰되지 않았다.

   릿지 회귀 5-fold 교차검증 결과 궤적 특징의 설명력(R^2)은
   진행방향 성분 +3.3%, 수직 성분 -1.3% 로 매우 낮았다.
   (음수는 개인 평균만 차감하는 상수 보정보다 못하다는 뜻)

4-2. 2단계 (120회)
   보정 없음 : 평균 오차 11.236px, 성공률 65.00%
   AI 보정   : 평균 오차 10.957px, 성공률 66.67%

   오차 거리 : 2.48% 감소, 대응표본 t-검정 p = 0.032 (Cohen's d = -0.198)
   성공률    : +1.67%p, McNemar 정확검정 p = 0.754 (성공 전환 6건, 실패 전환 4건)

   → 보정이 클릭을 중심 쪽으로 유의하게 당겼으나 성공/실패를 뒤집을 정도는
     아니었다. 다만 두 지표를 동시에 검정했으므로 다중비교를 보정하면
     p = 0.064 로 기준선을 넘지 못한다.

   주의 : 2단계는 1단계보다 성적이 나빴다(오차 9.30 -> 11.24px, p = 0.002)
   반면 반응시간은 빨라졌다(647 -> 600ms, p < 0.001). 2단계 내부에는 피로
   추세가 없으므로(r = 0.001) 세션 간 컨디션 차이로 판단된다.

4-3. 3단계 (240회, 분석 238)

     조건            성공률    오선택률   미스율
     A 보정 없음     69.33%     2.10%    28.57%
     B AI 보정       71.01%     2.10%    26.89%
     C 스냅          93.70%     6.30%     0.00%
     D 결합          92.86%     7.14%     0.00%

   Cochran's Q (성공률) = 156.98, p = 8.2e-34
   A vs C : p = 4.3e-13 (Bonferroni 보정)
   C vs D : p = 0.625  → 통계적으로 구별되지 않음

   간격별 오선택률
     0px(맞붙음)  A 3.80 / B 5.06 / C 5.06 / D 6.33 (%)
     5.53px(1시그마) A 2.50 / B 1.25 / C 7.50 / D 8.75
     16.60px(3시그마) A 0.00 / B 0.00 / C 6.33 / D 6.33


5. 고찰

5-1. 스냅이 예상보다 강했던 이유
당초 간격이 0px일 때 스냅의 오선택률이 급증할 것으로 예측했으나 그렇지 않았다.
기하학적으로 설명된다. 간격 0px에서 인접 버튼 중심은 2r 떨어져 있으므로,
목표 중심에서 r 이내(축 방향) 또는 1.41r 이내(대각 방향)의 클릭은 여전히
목표가 최근접이다. 즉 버튼을 살짝 벗어난 클릭도 스냅이 정확히 회수한다.
실제로 보정 없음 조건에서 미스한 68건 중 58건(85.3%)을 스냅이 목표로
회수했고 엉뚱한 버튼으로 보낸 것은 10건(14.7%)뿐이었다.

5-2. 결합(D)이 스냅(C)을 개선하지 못한 이유
모델이 산출한 보정 벡터의 크기가 중앙값 1.82px(최대 3.53px)인데 버튼 반지름은
10~15px이다. 최근접 판정을 뒤집으려면 인접 버튼과의 수직이등분선을 넘어야
하는데 1.8px로는 넘지 못한다. 실제로 238시행 중 스냅 결과가 바뀐 것은 4건
(1.7%)에 불과했다.

5-3. 3시그마 조건의 설계상 한계
sigma가 5.535px로 작아 3시그마 간격이 16.60px인데 버튼 반지름이 10~15px이다.
즉 간격이 버튼보다 작다. 인접 중심 거리는 각각 2.00r / 2.46r / 3.39r 로
세 조건이 모두 좁은 편에 속했고, 당초 3시그마에서 기대한 "충분히 분리된
배치" 조건이 성립하지 않았다. 이 때문에 간격에 따라 유불리가 역전되는
그래프를 얻을 수 없었다.

5-4. 회전 좌표계에 대한 재검토
오차를 진행 방향 기준으로 회전해 분해하면 방향이 다른 시행끼리의 상쇄를
막을 수 있다고 전제했으나, 이 참가자에게는 반대로 작용했다.
1단계 375시행에서 화면 좌표 기준 세로 오차가 -1.28px (t = -3.28)로 재현되는
상향 편향을 보였는데, 이를 진행 방향으로 회전하면 8방향 평균에서 정확히
상쇄되어 사라진다. 고정 오프셋은 회전이 죽이고 방향 의존 성분은 회전이
살리므로, 참가자별로 어느 쪽이 지배적인지 먼저 확인해야 한다.


6. 부수 관찰 — 궤적의 멈칫 구조

궤적을 속도의 국소 최소점으로 분해해 멈칫 지점을 검출했다. 1단계 데이터를
독립된 두 부분(150회 / 230회)으로 나누어 확인한 결과 재현성이 높았다.

   멈칫 위치(1.0 = 클릭점) 중앙값 : 0.990 / 0.975
   경로의 80~105% 구간 집중 비율  : 74.4% / 71.7%
   클릭까지 남은 시간 중앙값      : 228ms
   최소 속도 / 봉우리 속도        : 0.047 (거의 완전 정지)

즉 "목표 근처 도착 → 정지 → 미세 조정 → 클릭"의 구조가 관찰된다.
경로 형태는 직선+중간정지 40~44%, 옆으로 빠졌다가 꺾임 30~34%,
멈칫 없는 단발 13%, 직선+오버슛 12% 로 분포했다.

이 정지 구간 때문에 진행 방향 추정 창을 당초 80ms에서 150ms로 늘려야 했다.
80ms 창에서는 변위가 3px 미만인 시행이 73%에 달해 방향 추정이 불안정했으나,
150ms로 늘리자 94.7%가 정상 처리되었다.

다만 이 멈칫 특징들을 모델 입력에 추가하면 교차검증 R^2가 -1.7%에서
-3.2%로 오히려 악화되어(과적합) 최종 모델에는 포함하지 않았다.


7. 검증 절차에 관한 기록

표본이 제한된 상태에서 여러 특징을 시험하면 우연히 맞는 것을 고르게 되므로,
1단계 400회를 앞 150회(탐색)와 나머지 230회(검증)로 나누어 탐색 단계에서
유의했던 가설 3개를 검증셋에 한 번만 적용했다.

  가설 1 (수직 성분 한쪽 편향)  탐색 -1.05px(t=-2.17) → 검증 -0.15px(t=-0.37)
  가설 2 (마지막 멈칫-클릭 시간과 오차의 상관) 탐색 r=-0.254 → 검증 r=-0.033
  가설 3 (경로 패턴별 오차의 단조 관계)  탐색에서는 단조 관계, 검증에서 순서 역전

세 가설 모두 재현되지 않았다. 400회 전체를 보고 골랐다면 이를 발견으로
보고했을 것이다. 같은 이유로 0단계 15시행에서 관찰된 수직 편향 -5.79px 도
400회에서는 -0.30px로 사라졌다.


8. 결론

궤적 학습 기반 보정은 오차 거리를 통계적으로 유의하게 줄였으나(2.48% 감소,
p = 0.032) 성공률을 의미 있게 올리지 못했고, 최근접 스냅과 결합했을 때
스냅 단독보다 나아지지 않았다(p = 0.625).

실용적으로는 격자 배치 UI에서 최근접 스냅이 훨씬 효율적이다. 성공률을
69.33%에서 93.70%로 올리며 구현도 단순하다. 결합이 의미를 가지려면 보정량이
버튼 간 경계 여유와 비슷한 규모여야 하는데, 그러려면 궤적의 설명력이
현재(R^2 3%)보다 훨씬 커야 한다.


9. 한계 및 후속 계획

한계
 - 참가자 1명. 개인 편향의 참가자 내 분산과 참가자 간 분산을 비교할 수 없다.
   이 참가자에게 신호가 약하다는 것이 모두에게 그렇다는 뜻은 아니다.
 - 1단계와 2단계의 수행 수준이 유의하게 달라 조건이 완전히 동일하지 않았다.
 - 3시그마 조건이 설계 의도대로 작동하지 않았다.
 - 2단계 120회는 성공률 차이를 검정할 검정력이 부족하다.

후속 계획
 (1) 참가자를 최소 8명으로 확대한다. 편향의 개인차 존재 여부가 이 연구의 전제다.
 (2) 간격 설계를 sigma 배수 대신 버튼 반지름 배수(0 / 1r / 3r)로 변경한다.
     sigma가 작은 참가자에게 3시그마가 무의미해지는 문제를 피할 수 있다.
 (3) 보정 적용 임계값을 재설정한다. 현재 기준(반지름의 0.5배)은 실제 보정량
     1~2px과 두 자릿수 차이가 나 사실상 모든 보정을 무효화한다.
 (4) 참가자별로 고정 오프셋과 방향 의존 성분 중 어느 쪽이 지배적인지 먼저
     확인한 뒤 좌표계를 선택한다.
