# 개인화 마우스 보정 실험 (웹 프로토타입)

**UI 인식 · 시선추적 · 개인 클릭 패턴 학습의 기여도 분리 검증**
대전과학고 2026 기초자율연구 — 주영준 · 고민혁 (지도 이가연)

`2026 기초자율연구 최종 연구계획서.hwp` 와 `실험설계서.docx` 를 그대로 구현한
실행 가능한 실험용 웹페이지입니다.

---

## 무엇을 하는가

설계서의 세 신호를 **같은 브라우저 런타임 · 같은 좌표계**에서 결합합니다.

| 요소 | 구현 |
|---|---|
| 시선추적 | WebGazer.js (웹캠), 클릭 직전 200–300ms 시선 버퍼 → 화면 **구역** 판별 |
| UI 인식 | DOM `getBoundingClientRect` 로 버튼 위치·크기 직접 읽기 |
| 개인 클릭 패턴 | 누적 클릭 오차 벡터(방향·크기)의 실행평균 학습 |

**보정 원칙(설계 5장):** 버튼을 직접 실행(Invoke)하지 않고 **좌표 기반 보정만** 수행하며,
세 신호가 **일치할 때만** 보정합니다. 불일치 시 원 클릭을 그대로 통과시켜 오보정을 방지하고,
그 안전성을 **오보정률**로 측정합니다.

## 실행 방법

### 방법 1 — 로컬 서버 (권장, 시선추적 사용 시)
```bash
cd experiment
python -m http.server 8731
```
브라우저에서 <http://localhost:8731> 접속.
웹캠 권한을 허용해야 시선추적(WebGazer)이 동작합니다.

### 방법 2 — 파일 직접 열기
`index.html` 을 브라우저로 열어도 C0·C1(시선 미사용) 실험은 동작합니다.
(일부 브라우저는 `file://` 에서 웹캠을 제한하므로 시선 기능은 방법 1을 권장.)

> 인터넷이 없으면 WebGazer CDN 로드가 실패하고 시선 기능만 비활성화되며,
> UI·개인패턴 기반 조건은 정상 동작합니다.

## 사용 절차

1. **참가자 ID** 입력, 셀당 반복 수·격자·시선 사용 여부 설정.
2. **WebGazer 보정** — 빨간 점 9개를 응시하며 각 5회 클릭.
3. **예비실험 A** — 시선 구역 판별 정확도 특성화 (설계 6장).
4. **예비실험 B** — DOM 읽기 지연·정확도, 방해 버튼 밀도 영향.
5. **본실험 (C0–C4)** — HOME 클릭 → 표적(●) 클릭. 아래 5조건 전부 수행.
6. **결과·분석 보기** → JSON/CSV 내보내기.

### 보정 조건 (독립변인)
| 조건 | 시선 | UI | 개인패턴 | 역할 |
|---|---|---|---|---|
| C0 무보정 | – | – | – | 기준선(baseline) |
| C1 UI만 | – | ○ | – | DOM 스냅 단독 |
| C2 시선만 | ○ | – | – | 시선 구역 판별 단독 |
| C3 시선+UI | ○ | ○ | – | 결합 판별 (접근법 1) |
| C4 전체 | ○ | ○ | ○ | 결합 + 개인 학습 (최종) |

C0–C3 블록 순서는 참가자별 균형화, C4는 데이터 누적 후 마지막 배치.

### 난이도(Fitts 조작)
버튼 크기(작음/큼) × 이동 거리(가까움/멂) × 시간 압박(없음/있음) 완전교차.

## 측정·분석 (설계 4.3 / 7장)

- **명중률 · 오류율**, **보정 후 유효 클릭 오차(px)** vs **원클릭 오차(px)**
- **평균 이동시간(MT)**, **시선-클릭 시간차**(H2 선행성)
- **오보정률**(안전성) — 보정이 틀린 버튼으로 유도한 비율
- **요소 기여 분리**: C0→C1(UI) · C0→C2(시선) · →C3(결합) · C3→C4(개인학습) 증분
- **H1 개인 패턴 일관성**: C0 오차 벡터의 평균저항 R̄(0=무작위, 1=완전일관)
- **H5 난이도 상호작용**: 어려운 조건일수록 보정 이득이 큰가

### 기록 데이터 (시행당)
마우스 원클릭 좌표·궤적·타이밍, 보정 좌표, 표적/방해 버튼 DOM 사각형,
시선 구역·신뢰도·표본 수·선행시간, 조건·난이도, 판정·오보정 여부.
`localStorage` 에 자동 저장되며 JSON·CSV로 내보낼 수 있습니다.
